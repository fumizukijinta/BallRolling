# 要件定義 — BallRolling

3D傾け迷路ゲーム。**球体の玉**を、正方形の区画（グリッド）で組まれた箱で傾けて転がし、入り口から出口へ導く。（2026-09-06変更: 初期要件の「正方形の玉」は迷路の区画を指す表現と判明し、玉は球体に確定）

## 確定済み仕様

| # | 項目 | 仕様 |
|---|---|---|
| 1 | 箱（迷路ボード） | 正方形の玉を転がす箱を用意する |
| 2 | 入り口/出口 | それぞれ1つずつ存在する |
| 3 | 迷路 | 入り口から出口まで迷路構造。壁はリスタート毎にランダム再生成（到達可能性は常に保証） |
| 4 | ゴール | 玉が入り口から入り、出口から出ることを目指す |
| 5 | 操作 | 上下左右キーで箱を傾け、玉を転がして移動する |
| 6 | 開始 | スペースキーでゲーム開始 |
| 7 | 制限時間 | 開始と同時に3分（180秒）のカウントダウン |
| 8 | アイテム | 行き止まりの**どこか1箇所にだけ**アイテム1個が置かれる |
| 9 | 評価 | ゴールしたら評価画面（星表示）。**1分以内クリア +2／2分以内クリア +1（排他）／アイテム取得 +1**。1点ごとに★1つ、最大★★★ |

## 確定した詳細決定（2026-09-05 ユーザー承認済み）

- 迷路サイズ: **10×10**
- カメラ: **箱と一緒に傾く**（画面上ボードは常に正対、玉の転がる方向が直感的に分かる）
- 評点の具体例: 1分以内+アイテム=3点(★★★)／2分以内+アイテムなし=1点(★☆☆)
- 入り口: 外周の対角（画面左下）、出口: 対角（画面右上）。トップダウンカメラで緑=入り口、赤=出口に表示

## 実装時の細部（実装側で決定、変更は設計書に反映）

- 玉の出現: 開始時に入り口の上から落下して登場
- ゴール判定: 出口の穴から玉が落下したらクリア
- 時間切れ: 「TIME UP」表示 → Spaceでリスタート（迷路再生成）
- 見た目: プリミティブ+マテリアル色分けのみ（追加アセットなし。効果音は後日）
- 入力: Input System（矢印キー+Space）
